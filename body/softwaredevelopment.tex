\section{Business Context \& AI Integration}
\label{section:businesscontext}
Electronic manufacturing facilities, especially those utilizing conventional equipment, face significant challenges in optimizing production schedules. The manual scheduling processes currently employed in these facilities rely heavily on human experience and intuition, leading to inefficient resource allocation, extended machine idle times, and suboptimal production sequencing. These challenges create an ideal application scenario for artificial intelligence techniques.

Within this workflow, the AI component processes the machine specifications, product requirements, and manufacturing constraints to generate optimized schedules. The integration occurs primarily at the scheduling decision point, where conventional systems would typically rely on manual planning methods.

The implementation of AI in this context is justified by several key factors. First, the scheduling problem in electronics manufacturing presents considerable complexity, with factorial growth in the solution space as machines and tasks increase. For even a modest factory with 10 machines and 50 tasks, the number of possible schedule configurations becomes astronomically large, beyond what human planners can effectively evaluate.

Second, the scheduling environment is dynamic, with frequent changes in machine availability, production priorities, and manufacturing requirements. Traditional rule-based systems struggle to adapt to these constantly changing conditions without significant manual intervention.

Furthermore, the manufacturing scheduling problem can accept near-optimal solutions that balance multiple objectives. The ability to generate schedules that are 95\% optimal in a matter of minutes provides significantly more value than theoretical perfectly optimal schedules that might require a large amount of time for computation. The genetic algorithm approach selected for TaskAlign offers this favorable balance between solution quality and computational efficiency.

By integrating AI at this crucial decision point, TaskAlign transforms the traditionally experience-dependent scheduling process into a data-driven optimization framework while maintaining appropriate human oversight and intervention capabilities.

\section{Task Requirements Analysis Using AI Canvas}
\label{section:coding-standards}

\subsection{AI Task Requirements}

\subsubsection*{Requirements (REQ)}
The AI scheduling component must:
\begin{itemize}
  \item Generate optimized production schedules for electronics manufacturing that assign specific tasks to machines over time
  \item Consider all machine constraints including capabilities, cooldown times, and maintenance schedules
  \item Respect product assembly dependencies and component prerequisites
  \item Optimize for user-specified criteria, primarily minimizing total production time (makespan) and maximizing machine utilization
  \item Generate valid schedules within 5 minutes for problems involving up to 15 machines and 100 tasks
  \item Provide schedule visualization data for Gantt charts and timeline views
  \item Support both \textbf{Fresh Start} and \textbf{Production Resume} modes for schedule generation
\end{itemize}

\subsubsection*{Specifications (SPEC)}
The AI component will employ a genetic algorithm (GA) optimization approach with the following technical specifications:

\paragraph{Encoding Mechanism}
\begin{itemize}
  \item Each candidate solution (chromosome) represents a complete production schedule
  \item Schedule encoding uses a priority-based representation where genes represent task priorities for assignment to specific machines
  \item Encoding incorporates machine eligibility constraints to ensure only valid assignments are considered
\end{itemize}

\paragraph{Algorithm Structure}
\begin{itemize}
  \item \textbf{Population size}: Adaptive based on problem size (50--200 chromosomes)
  \item \textbf{Selection method}: Tournament selection with elitism (preserving top 10\% solutions)
  \item \textbf{Crossover operator}: Order-based crossover preserving task dependencies
  \item \textbf{Mutation operator}: Swap mutation with constraint preservation
  \item \textbf{Termination criteria}: Convergence (no improvement for 50 generations) or time limit (180 seconds)
\end{itemize}

\paragraph{Fitness Evaluation}
\begin{itemize}
  \item \textbf{Primary objective}: Minimization of makespan (total completion time)
  \item \textbf{Secondary objectives}: Machine utilization maximization, workload balance
  \item \textbf{Constraint handling}: Penalty function for violations, with repair mechanisms
  \item \textbf{Multi-objective optimization}: Weighted sum approach with user-adjustable weights
\end{itemize}

\subsubsection*{Environment (ENV)}

\paragraph{Technical Environment}
\begin{itemize}
  \item No direct connection to manufacturing equipment (no sensor data feed)
  \item Database integration for storing and retrieving machine/product specifications
\end{itemize}

\paragraph{User Environment}
\begin{itemize}
  \item Data manually input by factory staff with varying technical expertise
  \item Web-based interface for schedule generation and visualization
  \item Non-real-time operation (batch processing model)
  \item Operation within traditional electronics manufacturing facilities
\end{itemize}

\paragraph{Operational Constraints}
\begin{itemize}
  \item Computation time limited to 5 minutes maximum for user acceptance
  \item Schedule generation triggered on-demand, not continuously
  \item Support for factories with 5--15 machines and 20--100 concurrent tasks
  \item Compatibility with legacy manufacturing processes and equipment
\end{itemize}

\subsection{AI Ingegration in User Interfaces}
TaskAlign integrates AI functionality through several key interfaces, as shown in the mockups in Figures 3.1-3.9 of the project proposal. The most important AI-related interface elements including

\begin{enumerate}
    \item \textbf{Data Input Screens (Machine Management, Product Management, Assembly Process)}
 
    These screens allow users to input the data necessary for the AI to generate optimized schedules. The interfaces are structured to collect precisely the information the AI requires while remaining intuitive for non-technical users.
    
    \item \textbf{Scheduling Mode Selection}
    
    Users can choose between \textit{"Fresh Start Mode"} for new production planning and \textit{"Production Resume Mode"} for continuing partially completed production runs. This directly configures how the AI approaches the optimization problem.
    
    \item \textbf{Schedule Visualization}
    
    The AI's output is presented through multiple visualizations which are
    \begin{itemize}
        \item Gantt charts showing task assignments and timing (Figure 3.8)
        \item Monthly calendar views for longer-term planning (Figure 3.9)
        \item Daily schedule details for immediate implementation (Figure 3.10)
    \end{itemize}
    
\end{enumerate}

The interface design prioritizes clarity and usability while ensuring the AI component receives accurate input data and presents its results in an actionable format.

\subsection{AI Interaction Model}

TaskAlign primarily employs a \textit{Prompt} interaction model, where the AI suggests optimized schedules that users can review, potentially adjust, and implement. This model:
\begin{itemize}[nosep,leftmargin=*,topsep=2pt, partopsep=0pt, itemsep=1pt]
    \item Respects the expertise of factory managers by positioning the AI as a decision support tool rather than an autonomous system.
    \item Maintains human oversight and judgment in the scheduling process.
    \item Allows gradual trust-building as users observe the AI's performance over time.
\end{itemize}


The system also incorporates elements of the \textit{Annotate} model by providing context-enhancing information alongside schedules, including:
\begin{itemize}[nosep,leftmargin=*,topsep=2pt, partopsep=0pt, itemsep=1pt]
    \item Utilization statistics for each machine.
    \item Identification of potential bottlenecks.
    \item Visualization of dependencies between manufacturing steps.
\end{itemize}

\subsection{User Feedback Mechanisms}
\label{subsec:user_feedback_mechanisms_continued} % Added _continued if it's a continuation

TaskAlign incorporates several mechanisms for users to provide feedback on AI-generated schedules, including

\paragraph{Direct Schedule Adjustment}
Users can manually modify generated schedules through the Gantt chart interface. These adjustments are logged and can be analyzed to understand where the AI's solutions may not align with practical requirements.

\paragraph{Schedule Acceptance Tracking}
The system records whether generated schedules are accepted as-is, modified before implementation, or rejected entirely, providing quantitative feedback on AI performance.

\paragraph{Structured Feedback Forms}
After implementing a schedule, users can complete a brief evaluation form rating schedule quality and noting any issues encountered during implementation.

\paragraph{Issue Reporting}
A dedicated mechanism allows users to report specific problems with schedules (e.g., "This machine requires more cooldown time than scheduled") that can inform algorithm refinement.

\subsection{AI Value Proposition} 
\label{subsec:ai_value_proposition_continued} % Added _continued if it's a continuation

The AI component offers significant advantages over traditional scheduling by leveraging computational power to explore numerous near-optimal schedules, ensuring consistency and eliminating human bias. It efficiently manages complex interdependencies across machines, tasks, and constraints, and enables rapid scenario analysis for "what-if" planning. By encoding scheduling expertise in algorithms, it preserves organizational knowledge despite staff changes. These capabilities lead to tangible business benefits, including reduced production time, higher throughput, improved machine utilization, and more agile production planning—making AI a valuable asset for efficient, scalable, and adaptive manufacturing operations.

\paragraph{Deployment Environment}
The TaskAlign AI component will be deployed in a cloud-based environment for the following reasons

\begin{enumerate}[label=\arabic*., nosep,leftmargin=*,topsep=2pt, partopsep=0pt, itemsep=1pt]
    \item \textbf{Computational Requirements} 
    
    Genetic algorithms for complex scheduling problems require significant processing power that may exceed on-premises capabilities of target factories.
    \item \textbf{Centralized Maintenance} 
    
    Cloud deployment enables updates and improvements to the AI component without requiring on-site intervention.
    \item \textbf{Scalability} 
    
    Cloud resources can be dynamically allocated based on problem complexity, ensuring consistent performance regardless of scheduling scope.
    \item \textbf{Accessibility} 
    
    Cloud deployment supports the web-based interface, allowing access from multiple locations within the factory or organization.
\end{enumerate}

\subsubsection{Real-world examples or performance comparisons}
\label{ssubsec:poc_real_world_examples}

\paragraph{Example scenario}
Suppose a factory needs to produce a control board, power module, display unit, and final assembly, each with specific machine and dependency requirements.
\begin{itemize}[nosep,leftmargin=*,topsep=2pt, partopsep=0pt, itemsep=1pt]
    \item In the \textbf{manual approach}, each component is scheduled one after another, leading to significant idle time for machines and a longer overall production time.
    \item In the \textbf{AI-optimized approach}, the model automatically finds opportunities to run tasks in parallel (e.g., starting the power module and display unit as soon as their shared prerequisite is done), resulting in a much shorter production schedule.
\end{itemize}

The Gantt charts (referenced in Figure \ref{fig:poc_gantt_comparison}, or presented below if space allows) illustrate the difference in scheduling:
\begin{itemize}[nosep,leftmargin=*,topsep=2pt, partopsep=0pt, itemsep=1pt]
    \item \textbf{Manual:} All tasks are sequential; machines are often idle.
    \item \textbf{GA-Optimized:} Tasks are overlapped where possible; machines are used more efficiently, and the total production time is significantly reduced.
\end{itemize}
